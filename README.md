# AVEK — Avek AI Chat (Android)

`AvekChat.zip` contains the full Android Studio project for **Avek**, a fully customisable AI chat app
built with Kotlin, Jetpack Compose, Hilt, Room and DataStore. Models and conversations are simulated
on-device; the UI and architecture are production-grade.

**Open it:** unzip `AvekChat.zip`, then in Android Studio choose **File → Open** and select the
`AvekChat` folder. Full feature list, architecture notes and screenshots are in `AvekChat/README.md`.
